# soybean_metagenomics_analysis
R scripts for taxonomic and functional analysis of soybean rhizosphere metagenomes from Leonard investigating microbiome responses to iron deficiency chlorosis (IDC).

Scripts are numbered according to the analysis workflow:

•	“01_preparing_metagenomics_phyloseq.R” – preparation of metagenomics phyloseq object.

•	“02_metagenomics_bacteria_to_fungi_ratio.R” - bacterial and fungal read counts and bacteria-to-fungi ratio calculations across different fertilizer treatments in the soybean rhizosphere at Leonard in 2022.

•	“03_metagenomics_bacterial_community_analysis.R”- alpha diversity, beta diversity, compositional and statistical analyses of soybean bacterial communities under different fertilizer treatments at Leonard in 2022.

•	“04_ metagenomics_bacterial_species_level_differential_abundance_analysis.R” - species-level differential abundance analyses using DESeq2 for Pseudomonas, Bradyrhizobium, Variovorax, and Arthrobacter between high and no fertilizer treatments in the soybean rhizosphere at Leonard in 2022. 

•	“05_metagenomics_fungal_community_analysis.R” - alpha diversity, beta diversity, compositional and statistical analyses of soybean fungal communities under different fertilizer treatments at Leonard in 2022.

•	“06_ metagenomics_rhizosphere_community_functional_analysis.R” - differential abundance analyses using DESeq2 of DRAM-derived functional modules between high and no fertilizer treatments in soybean rhizosphere from Leonard in 2022. 

Data availability
Raw sequencing data and large data files are not included in this repository. Sequencing data accession information will be provided with the associated publication.
